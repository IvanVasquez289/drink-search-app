# 🍹 Drink Search App

A modern React + TypeScript application to discover drinks and their recipes. It combines traditional search with AI-powered suggestions to help users find the perfect beverage.

## 🚀 Features

- Search for drinks by name or ingredient  
- View detailed recipes with ingredients and instructions  
- Get AI-powered drink suggestions via natural language prompts (OpenRouter)  
- Save your favorite drinks  
- Responsive and fast user experience  
- Smooth navigation with client-side routing
